## 当前产品与视觉

首版菜单栏宿主、独立窗口/后台、两种提醒、历史、持久化、标准 MCP 和 CLI 均已实现。用户在实际全屏提醒验收后要求主窗口配色靠拢，并明确否定偏绿背景；当前为中性烟灰的“雾灰”主题、浅色文字、原生液态玻璃和独立背景，不使用黄色按钮。设置保留明亮和跟随系统。不要回退到奶油棕、浅灰蓝大面积亮白、整窗透明或绿色背景。

实际安装位于 ~/Applications/Meno.app；dist/Meno.app 与 dist/Meno.zip 为本地交付包。构建身份、架构、Git revision、源码摘要、依赖与三个可执行文件摘要记录在 dist/build-info.json；SHA256SUMS 可校验 ZIP 和清单。旧安装保留为 Meno.previous.<时间>.app，原提醒数据和首轮验收归档不删除。

## 工程入口与验证

使用 `make test`、`make build`、`make integration`、`make verify`。Python MCP 测试使用 3.12 和 scripts/requirements-mcp.lock.txt；安装步骤见 README。CLI 参数解析位于 packages/MenoCLIKit，主业务仍由界面、MCP 和 CLI 共用。测试套件为 55 项 Swift 测试，以及真实 MCP/CLI、断连、并发、进程恢复集成测试。本机已通过，日志在 test-results/；远端 CI 在 Apple Silicon/Intel 的 macOS 26、Xcode 26.6 上运行并保留构建和测试产物。

隔离集成套件复制 App 并使用本次独立 Bundle ID、通知命名空间和私有临时目录，避免影响日常 Meno；测试副本结束后正常退出。源码及工程文档分支为 codex/meno-v1；远端仓库 adolfheir/Meno 原先为空，本次建立首个提交并推送，没有创建或合并 PR。
