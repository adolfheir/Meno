## 未完成原因与已知限制

系统通知当前未授权。通知授权弹窗属于受保护的 `com.apple.UserNotificationCenter`，桌面工具明确拒绝操作该系统 App；没有通过其他工具绕过此限制。需要用户手动在 macOS 通知设置中允许 Meno，之后才能补测 banner、通知中心送达、通知按钮和原生待触发请求清理。不能把提交成功或假客户端结果当作已看见通知。

机器在验证过程中进入锁屏，系统 API 返回 screenLocked=true，新全屏实例按约定暂缓展示；没有尝试解锁、输入凭据或操控登录界面。因此完整全屏图片、实际按钮／Esc、全屏应用、Spaces、台前调度及解锁后恢复仍待实机测试。共享开发机上有其他工作，未执行整机重启、休眠或修改全局时区，也未以程序模拟这些场景冒充真机验收。

首版只提供单次、每天和周一至周五；不含节假日／调休、云同步、进程隔离、第三方热安装或 App 内 AI。系统通知滚动容量为最近 60 条，较远计划保留并明确返回暂未提交原因；宿主异常退出时，已提交的一次性系统通知可能仍送达，后续周期和全屏依赖宿主运行。睡眠中不强制唤醒，超过 30 分钟的遗漏不补弹。签名和打包仅验证当前 arm64 本机。

首轮交付时源码尚未提交，此描述仅属于历史阶段；当前提交和推送状态见上方当前交付与阶段交接。原交接文档、参考图和数据均保留。
