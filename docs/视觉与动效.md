# Meno 视觉与动效

## 当前配色：与全屏提醒对齐

2026-10-23 后续验收时，用户实际看过全屏提醒并认可视觉，要求主 App 配色向其对齐，并明确否定偏绿背景。当前默认“雾灰”使用中性烟灰渐变、浅色文字与克制的玻璃高光，减少此前浅灰蓝方案的大面积亮白。空状态图形也改为银灰，按钮保持中性，没有黄色。设置保留“明亮”和“跟随系统”；已有明确选择不被升级覆盖，本次安装通过设置切换到雾灰。

普通窗口仍有独立、不透明背景；全屏提醒的蒙层、灰绿确认按钮和交互保持原样。主窗口、设置和空状态共享语义色板，回退界面与辅助功能策略保持一致。下文浅灰蓝是前一阶段的设计依据，当前配色以上述版本为准。

2026-10-23，用户在试用后明确要求参考 Ahaya 测试机 App 和 macOS 控制中心的液态玻璃质感，保留 Meno 自己的布局与辨识度；随后明确要求按钮不使用黄色。之前的奶油棕与柔白实色方案已被本稿取代，既有验收截图保留作历史记录。

## 材质和层次

macOS 26+ 使用系统原生 `glassEffect`、`GlassEffectContainer` 和玻璃按钮样式。主要操作区、时间按钮、状态胶囊、搜索、筛选和提醒类型菜单都采用玻璃材质。相近的玻璃控件放在容器中统一采样；筛选选中项使用 `glassEffectID` 参与系统的形变过渡。文字采用系统语义前景色，随材质环境保持可读。[Apple 自定义液态玻璃文档](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)

窗口使用独立、不透明的浅灰蓝渐变画布，叠加低饱和青灰与浅紫光晕；原生玻璃控件采样应用自己的背景。曾试过整窗透明玻璃，但它会透出其他 App 的文字，用户明确要求增加背景，最终已移除该方案。现在没有其他窗口内容穿透，背景绘制不承担玻璃折射与交互的模拟。

按钮、菜单和选中状态使用中性透明玻璃，去掉黄色填充与黄色文字。提醒类型使用圆润玻璃菜单，自选时间与快捷时间统一高度和轮廓，输入标题、返回图标、时钟和标签对齐。装饰性的日出图形保留少量柔和暖色，运行状态用低饱和灰绿圆点表达。

macOS 14 / 15 保留材质与清晰控件回退，不称为原生液态玻璃。开启系统“降低透明度”时使用实色面板和明确边界；不修改用户的系统设置。构建需要 Xcode 26+，部署目标仍为 macOS 14。

## 动效

玻璃按钮采用系统按压和悬停响应；筛选高光随选中项平滑移动。展开区、列表变更和保存回执使用短暂的轻弹性与淡入，回执最多位移 6 pt，不延迟业务操作。开启系统“减少动态效果”时，显式过渡即时完成，原生控件遵循系统设置。

空状态使用 Meno 自己的日出图形，上下移动幅度 2 pt，周期约 5.6 秒；离开空状态或应用不再处于活动状态时暂停。动画不挂在提醒后台运行时上。减少动态效果时图形保持静止。
